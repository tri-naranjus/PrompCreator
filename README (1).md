# 🕹️ Creador de Prompts Perfectos

Esta es una aplicación web desarrollada en **React + Vite + Tailwind CSS**, con estilo ochentero, que ayuda al usuario a crear prompts eficaces para usar con inteligencia artificial (ChatGPT, Gemini, etc).

---

## 🚀 ¿Qué hace esta app?

- Permite al usuario seleccionar qué desea generar: texto, imagen, etc.
- Propone roles para que la IA actúe como (ej: profesor, médico, diseñador...).
- Permite escribir un contexto detallado y elegir el estilo o tono del resultado.
- Genera un prompt claro y optimizado listo para copiar y usar.
- ¡Con un fondo animado de marcianitos al estilo arcade retro! 👾

---

## 🛠️ Cómo ejecutar localmente

1. **Clona este repositorio:**

```bash
git clone https://github.com/tuusuario/creador-prompts-app.git
cd creador-prompts-app
```

2. **Instala las dependencias:**

```bash
npm install
```

3. **Inicia la app en modo desarrollo:**

```bash
npm run dev
```

4. Abre tu navegador en `http://localhost:5173`

---

## 🌐 ¿Cómo publicarlo?

Te recomendamos usar [Vercel](https://vercel.com):

1. Crea una cuenta y conecta tu cuenta de GitHub.
2. Sube este proyecto a un nuevo repositorio en GitHub.
3. Desde Vercel, selecciona el repositorio y despliega automáticamente.
4. Obtendrás un link como `https://creador-prompts.vercel.app`
